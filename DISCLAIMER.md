## Artificial Intelligence & Hybrid Cyber-Hardening Notice

The AI-generated clinical reports are synthesized using Large Language Models (LLMs) running on cloud LPU infrastructures (such as `groq:llama-3.3-70b-versatile`), compounded by local deterministic mathematical frameworks.

Although robust multi-stage validation layers, semantic XML guardrails, and RAG constraints are strictly enforced, AI models are susceptible to adversarial exploits. To mitigate this risk, the application implements a strict **Synchronous Regex Gateway Firewall** at the backend layer (`app.py`) to intercept word boundaries (`\b(IGNORE|OVERRIDE|CLEAN|SYSTEM RESET|DAN)\b`), filtering malicious payload injections before API serialization. However, because AI-generated outputs may still contain unexpected behavior, every generated report must be audited by qualified healthcare professionals before clinical utility.
