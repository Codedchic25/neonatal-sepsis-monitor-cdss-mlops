# 🛡️ CLINICAL & TECHNICAL CODE OF CONDUCT: SEPSIS MONITOR AI

## 1. Our Institutional Pledge

In the interest of fostering an open, welcoming, high-integrity, and clinically rigorous development environment, we as contributors, developers, researchers, and healthcare professionals pledge to make participation in the **Sepsis Monitor AI** project a professional, collaborative, and harassment-free experience for everyone. We welcome contributions regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity, level of experience, education, socio-economic status, nationality, or clinical role.

---

## 2. Standards of Medical & Technical Integrity

Because this Clinical Decision Support System (CDSS) targets high-acuity Neonatal Intensive Care Units (NICUs), our standards mandate absolute scientific accuracy, software quality, and strict data security protocols:
*   **Deterministic Accuracy:** Commit to implementing bio-mathematical algorithms (such as first-order exponential biomarker decay models and weight-based individualized dosage calculations) with strict deterministic validation layers.
*   **Algorithmic Transparency:** Ensure any modification affecting mathematical constants, pharmacokinetic coefficients, clinical thresholds, or LLM guardrails is fully documented, peer-reviewed, and verified by automated unit tests.
*   **Privacy & Data Protection:** Maintain robust data-handling boundaries through diskless in-memory PDF generation, strict regex input validation, and complete transactional cleanup of local clinical database snapshots.

---

## 3. Prohibited & Unacceptable Behavior

The following actions are strictly prohibited within the project community, GitHub repositories, issue trackers, and collaborative environments:
*   **Harassment & Attacks:** Utilizing sexualized language, imagery, unwelcome advances, trolling, insulting comments, or personal and political attacks.
*   **Data Leaks & Doxxing:** Publishing another person's private information, including unencrypted medical simulation payloads, infrastructure credentials, API tokens, or confidential configuration files.
*   **Malicious Sabotage:** Intentionally introducing unverified clinical thresholds, unsafe AI model temperatures, or code modifications engineered to bypass semantic medical safety guardrails and mandated empiric antibiotic protocols.

---

## 4. Governance & Enforcement Responsibilities

Project maintainers hold full responsibility for clarifying, interpreting, and enforcing this Code of Conduct to protect the project's clinical and engineering integrity:
*   **Corrective Actions:** Maintainers will take fair, immediate, and proportionate corrective action in response to any behavior considered inappropriate, threatening, or harmful.
*   **Repository Moderation:** Maintainers reserve the absolute right to remove, edit, reject, or reverse comments, commits, pull requests, code blocks, documentation, wiki edits, or issues that breach these standards.

---

## 5. Scope of Application

This Code of Conduct governs all official project spaces, including:
*   GitHub repositories, documentation files, source code comments, issue trackers, discussions, and pull request reviews.
*   Public settings where an individual officially represents the **Sepsis Monitor AI** platform, including scientific conferences, medical AI symposiums, engineering workshops, production deployment reviews, or academic presentations.
